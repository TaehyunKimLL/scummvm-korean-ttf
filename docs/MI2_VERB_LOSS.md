# MI2 다리 장면 동사 텍스트 소실 — 근본 원인

발견: 2026-09-05, 회귀 하네스 첫 실전. 커밋 `b74fe61b913` 의 불완전한 수정.

## 증상

MI2 한국어 hi-res(`mi2-svfn`, scale=3 alpha) 에서 **다리 장면(room 5) 진입 후
동사 메뉴가 통째로 사라진다.** 상단 문장줄("걸어가기")과 인벤토리 그림은
정상이라 눈에 잘 안 띈다.

측정 (동사 영역 y160-200, x0-160 의 밝은 픽셀):

| 빌드 | 픽셀 |
|---|---|
| upstream master | 549 |
| 우리 트리 (버그) | **16** |
| 우리 트리 (수정 후) | 384 |

384 와 549 의 차이는 글꼴 두께 차이지 누락이 아니다 (육안 확인:
"주기/가지기/사용하기/열기/관찰하기/밀기" 여섯 동사 모두 표시).

## 추적 과정

`clearTextSurface()` 호출부 5곳에 `who` 태그를 붙여 계측했다:

```
KAREA scoped=1 who=restoreCharsetBg area=(0,0)-(960,432) room=5   ← 정상
KAREA scoped=0 who=roomChange       area=(0,0)-(960,600) room=5   ← 범인
```

`restoreCharsetBg` 의 스코프 클리어는 `b74fe61b913` 이 제대로 고쳤다
(0~432 = 동사 위쪽만). 그런데 **그 직후 `roomChange` 가 전체(0~600)를
지운다.**

`drawVerb()` 에도 프로브를 넣어 확인한 결과:

```
room 별 KVERB 호출:  room=0 34회, room=1 4회, room=108 5회, room=5 2회
```

동사는 인터페이스가 처음 뜰 때 그려지고 그 뒤로는 거의 안 그려진다.
**master 도 호출 분포가 완전히 동일했다** — 즉 문제는 "그리지 않는 것"이
아니라 "그려둔 것을 지우는 것"이다.

## 근본 원인

`room.cpp` 의 방 전환 처리(`fadeOut` 직전)가 오버레이 **전체**를 지웠다.

동사 스트립은 방에 속하지 않는다. 인터페이스가 나타날 때 한 번 그려지고
그 뒤로는 아무도 다시 그리지 않는다. 반면 방 전환은 방마다 일어난다.
따라서 방을 하나 지날 때마다 동사가 지워지고 복구되지 않는다.

`markRectAsDirty()` 로 세 화면을 dirty 표시해도 소용없다. 그것은 게임
비디오 버퍼를 다시 합성할 뿐이고, 동사 **텍스트**는 별도 오버레이
서피스에 있어서 `drawVerb()` 가 다시 불리지 않는 한 돌아오지 않는다.

## 수정

방이 소유한 화면만 지우고 동사 대역은 건드리지 않는다:

```cpp
for (int i = 0; i < 3; ++i) {
    VirtScreen *v = &_virtscr[i];
    if (!v->h || v->number == kVerbVirtScreen)
        continue;
    clearTextSurface(v);
}
```

## 교훈

1. **`b74fe61b913` 이 같은 증상을 고쳤다고 했지만 절반만 고쳤다.**
   `restoreCharsetBg` 경로만 보고 `roomChange` 경로를 놓쳤다.
   호출부가 5곳인데 그중 1곳만 스코프를 받게 했다.

2. **회귀 하네스가 없었으면 못 찾았다.** 이 버그는 특정 방에 들어가야
   나타나고, 눈에 띄는 대사는 멀쩡해서 수동 테스트로는 놓치기 쉽다.

3. **픽셀 총량은 오도한다.** 동사 영역 전체 픽셀은 우리가 4,036,
   master 가 3,634 로 **우리가 더 많았다**. 배경 박스 색 때문이다.
   "밝은 픽셀만" 세야 글자가 보였다. LLM 시각 판정은 이 함정에
   걸리지 않고 바로 "왼쪽 동사 칸이 비었다"고 지적했다.

4. **시간축을 훑어야 한다.** 처음에 t=30 에서 3,471 을 재고 "동사가
   있다"고 판단했는데, 그 시점은 "Part I" 타이틀 카드였고 3,471 은
   타이틀 글자였다. 2초 간격으로 훑어 t=32→34 전환을 보고서야
   알았다.
